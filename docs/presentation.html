DAY 03 • BLOCK #5

ShopeeFood Restaurant CRUD WebApp

Ứng dụng Web Nhà Hàng kết hợp trải nghiệm đặt món ShopeeFood và kiến trúc quản trị SSR + ORM + Post/Redirect/Get (303).

1. Mô hình Dữ liệu (Database & Models)

  • Dish (Món ăn): id, name, description, price, originalPrice, category, available
  • Chef (Đầu bếp): id, name, specialty, experience, bio
  • Ingredient (Nguyên liệu): id, name, unit, stock, origin
  • Order (Đơn hàng ShopeeFood): Lưu thông tin khách đặt, danh sách món, mã giảm giá và trạng thái giao hàng.

2. Luồng Request & Chuẩn HTTP Method

Thao tác HTTP Method URL Status Code
Danh sách & Tìm kiếmGET/dishes?q=..., /admin/{resource}200 OK
Chi tiết bản ghiGET/dishes/:id, /admin/{resource}/:id200 OK / 404
Thêm bản ghi mớiPOST/admin/{resource}303 See Other / 400
Cập nhật bản ghiPATCH/admin/{resource}/:id?_method=PATCH303 / 400 / 404
Trang xác nhận xóaGET/admin/{resource}/:id/delete200 OK / 404
Xóa bản ghiDELETE/admin/{resource}/:id?_method=DELETE303 See Other / 404

3. Kiểm tra Bảo mật & Chất lượng Mã nguồn

  • Chống SQL Injection: 100% truy vấn sử dụng Parameterized Queries (? trên SQLite, $1, $2 trên PostgreSQL).
  • Chống Mass Assignment: Dữ liệu từ req.body đi qua hàm validate độc lập trong src/validators.js trước khi gọi model.
  • Bảo vệ Chuỗi kết nối: DATABASE_URL nằm trong .env (đã thêm vào .gitignore), không bao giờ truyền ra template EJS.
